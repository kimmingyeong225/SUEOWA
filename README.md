# SUEOWA
수어와 (SUEOWA)

농인이 혼자서도 여행할 수 있는 관광 안내 키오스크

부산 태종대유원지에 설치되는 수어 안내 서비스입니다. 관광지 정보를 3D 수어 아바타 영상으로 제공하고, 화면에서 다루지 못하는 질문은 107 손말이음 수어통역으로 연결합니다.

2026 캠퍼스 리빙랩 「지역문제 해결 아이디어 공모전」 출품작 · 부산농아인협회 협조

왜 만들었나

수어를 제1언어로 쓰는 농인에게 한국어 문자는 제2언어입니다. 관광지 안내가 있어도 문자 중심이면 온전히 전달되지 않습니다.

부산농아인협회 인터뷰(2026.6, 수어통역 진행)에서 세 가지가 확인되었습니다.

돌발 상황에서 막힌다 — 매표소 오류 시 벨을 눌러 음성으로 설명해야 하는 구조
설명이 전달되지 않는다 — 길 안내는 갖춰졌으나 역사·유래 설명은 닿지 않음
부산은 문자 안내조차 부족하다

태종대 현장 조사에서도 다누비열차 운행 중단과 대체 셔틀버스 안내가 현수막 문자 한 장으로만 제공되고 있었습니다.

화면 구성
화면	설명
대기	아바타가 수어로 인사하며 접근 유도. 화면 어디든 터치하면 시작
메뉴	카테고리 선택 + 107 연결 버튼
콘텐츠	선택한 주제의 수어 영상 연속 재생, 이전/다음 이동
107 연결	손말이음 안내 QR 표시
설문	얼굴 아이콘 5단계 평가 + 다중선택 + 자유의견
안내 콘텐츠
셔틀버스 안내 — 다누비열차 운행 중단, 무료 셔틀 이용 방법과 운행 시간
안전·통제 구역 — 신선바위·망부석 통제, 자갈밭 야간 출입 제한, 전망대 공사 안내
이용 안내 — 개방 시간
어떻게 만들었나

수어 영상의 동작은 임의로 만든 것이 아니라 실제 수어통역사의 시연에서 나왔습니다.

대본 작성 — 관광 정보를 농인이 이해하기 쉬운 문장으로
통역사 시연 촬영 — 카메라 3대로 정면·좌·우 동시 기록
동작 추출 — MediaPipe로 관절 좌표를 시계열 복원
아바타 적용 — Blender에서 보정 후 렌더링

검증은 두 번 거칩니다. 촬영 전 대본을 감수받고, 완성된 아바타 영상을 다시 확인받습니다. 수어는 손동작뿐 아니라 표정과 입모양이 문법이기 때문입니다.

기술 스택

바닐라 HTML / CSS / JavaScript 단일 페이지 구조입니다. 프레임워크나 빌드 과정이 없고, 인터넷 없이 로컬에서 그대로 구동됩니다.

화면 전환은 페이지 이동 없이 섹션 토글 방식
영상은 이중 버퍼(video 2개 교차)로 끊김 없이 연결
설문 응답은 Supabase에 저장, 실패 시 localStorage에 보관 후 자동 재전송
한국어 / English 자막 전환

대상 기기 — 갤럭시탭 A9+ (1920×1200), Android Chrome

실행 방법
로컬 실행
bash
node serve.js

http://localhost:8000/index.html 접속.

같은 네트워크의 다른 기기에서 접속

서버가 0.0.0.0에 바인딩되어 있어 같은 와이파이·핫스팟에 연결된 기기에서 접속할 수 있습니다.

노트북과 태블릿을 같은 네트워크에 연결
노트북에서 node serve.js 실행
터미널에 출력되는 LAN IP 확인 (또는 ipconfig)
태블릿 브라우저에서 http://<LAN IP>:8000/index.html

Windows 방화벽에서 Node.js 인바운드 연결 허용이 필요할 수 있습니다.

접근성 설계

농인 사용자를 전제로 만들었습니다.

소리에 의존하는 요소 없음 — 알림음·음성 안내 미사용, 모든 피드백은 시각
화면 전체가 터치 영역 — 버튼 조준이 어려운 사용자를 고려
광과민성 발작 방지 — 애니메이션 주기 2.5초 이상, 변화폭 5% 이내, 깜빡임 없음
문자 최소화 — 아이콘 중심 구성, 고령 농인의 문자 접근성 고려
오프라인 구동 — 현장 통신 환경과 무관하게 동작
알려진 한계
107 연결 — 손말이음은 한국지능정보사회진흥원이 운영하는 국가 서비스로, 외부 연동에는 기관 간 협의가 필요합니다. 이용자 가입도 요구되어 즉시 연결은 불가능합니다. 현재는 안내·유도 화면까지 구현했고, 연동 지점(connectTo107())을 분리해 두었습니다.
양방향 수어 인식 — 단일 카메라로는 깊이 정보를 얻을 수 없어 앞뒤 움직임이 많은 수어에서 오인식이 발생합니다. 확장 과제로 두었습니다.
다국어 — 국제수어는 한국수어와 다른 언어로 별도 감수 체계가 필요합니다. 현재는 자막 다국어(한/영)까지 지원합니다.
미촬영 콘텐츠 — 통역사 일정 확보의 어려움으로 일부 문장은 제작하지 못했습니다. 해당 클립은 자동으로 재생 목록에서 제외됩니다.
확장

화면과 콘텐츠가 분리된 구조라, 다른 관광지에는 영상 파일과 카테고리 정의만 교체하면 적용됩니다. 관광 안내는 내용이 자주 바뀌지 않아 재제작 비용이 거의 발생하지 않으며, 구독료 없이 운영됩니다.
